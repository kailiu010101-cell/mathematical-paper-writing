# 数学表达规则

本文件关注句子、公式、记号与证明的组织。**样本观察**来自已读论文；**用户偏好**来自用户 2026-09-18 的明确要求；**应用规则**是将两者转成写作决策的建议，不能一概宣称为刘凯本人的习惯。样本编号见 [来源记录](sources.md)。

**适用范围与边界：** 只用于英文科研论文写作，讨论和技能说明使用中文。用户已确认：英文直接克制；关键证明步骤展开、常规计算简写；文字采用短句引导、关键公式、必要解释；三次使用原则允许有理由的例外；不同估计优先用不同下标常数。

**纯润色只改英文表达。** 下文涉及增补公式、改变证明结构、换记号或常数编号的规则，只在新稿起草或用户明确要求相应重写时实施。对已有稿件润色时，保留公式、证明顺序、段落结构和引用，只把其他问题作为建议单列。

## 1. 文字与公式的分工

**样本观察：** B p.9 用稳定性不等式具体化定理结论；同页的证明把有界性核验写为连续估计，并解释分部积分和不等式依据。A p.11 通过矩阵分解、范数估计和渐近量级推进可行性分析。

**用户偏好：** 论文中不要一味用文字；采用“短句引导 → 关键公式或推导链 → 必要解释”，不逐字复述公式。

| 要表达的内容 | 优先形式 | 需要保留的说明 |
| --- | --- | --- |
| 参数的取值和约束 | 行内不等式；条件较多时集中列出 | 量词、取值域及参数依赖 |
| 稳定性、衰减、误差大小 | 范数或概率估计 | 初值、时间范围、常数条件、稳定性意义 |
| 计算怎样推出结论 | 对齐的等式/不等式链 | 非平凡步骤所用假设或工具 |
| 对象之间的结构关系 | 定义式、分块矩阵、系统方程 | 含义、空间/维数、必要的索引范围 |
| 为什么选这种构造 | 简短文字，必要时配决定性公式 | 构造要解决的具体障碍 |
| 与文献的差异、条件的局限 | 文字解释，比较具体界时辅以公式 | 比较对象与适用条件 |

**应用规则：** “误差逐渐变小”可能表示单调性、收敛或指数衰减，不能任选一种公式替代。只有上下文已确定精确含义时才公式化；否则指出缺少的信息。

已有短式能说明的关系，不先用一长段文字翻译一遍。公式中的加减乘除不再逐项口头复述；解释其作用或关键依据即可。

## 2. 一段围绕一个数学目标

**样本观察：** B p.9 的有界性证明先说要核验哪个条件，再展示估计，最后回到该条件；A pp.7–12 在较长证明中采用按目标命名的步骤。

**应用规则：** 一段通常交代目标或工具，给出关键推导，说明非平凡步骤的依据，最后在需要时点明本段的结论。这是内容关系，不是每段必须四句。不要把短证明拆成许多 Step，也不要给每个显然的代入都加一个小标题。

短范围和简单记号放行内；核心模型、主估计、复杂定义及多行推导独立显示。同一个推导按等号或不等号对齐。需要分别引用中间步骤时才细分标签；否则一个整体编号或不编号即可。维护已有稿件时保留被引用的标签。

## 3. 新辅助符号的“三次使用”规则

**用户偏好：** 新增辅助符号通常应在后文有三次及以上实质使用；这是一条允许例外的默认原则，若确实显著改善可读性，即使不足三次也可以定义。

- 先检查同一对象是否已有记号，不为同一误差、能量或条件换一个名字。
- 估计定义后的使用次数，**定义行不计**。真正参与推导、用于不同论证步骤或被后文调用才算实质使用；反复念出名称或复制同一行不能凑数。
- 只用一两次的短组合直接展开。长式只需回指时，引用原公式，不必再包装成新字母。
- 至少三次不代表必须引入记号；记号仍应比原式更便于理解和运算。低于三次但明显避免长式遮蔽结构、消除指代歧义或区分估计常数时，可作有理由的例外，不把“更简洁”当作泛泛借口。
- 在首次需要处引入，先想清用途，避免预先堆一页暂时用不到的符号。
- 检查名称冲突、上下标和作用域。局部证明记号不默认为全文通用。
- 起草完成后再看是否仍有复用价值。本轮新增但后来被删至低频的辅助缩写，若无例外理由，尽量还原为原式；不机械数 LaTeX 字符串。润色时不据此删改原有符号。

**必要的含义说明与新增缩写不同：** 模型的状态、控制、概率空间、参数或本文研究的性质首次出现必须说明含义，即使只在一个核心陈述中出现。不能为了满足计数而让对象未定义；此时就近说明，不再额外包装一个别名。

没有统计证据证明 A、B 所有符号都遵循三次门槛；此规则明确来自用户。

## 4. 正式定义、记号约定与引理

**样本观察：** A p.5 用普通定义式引入误差和矩阵；A pp.2–3 与 B p.8 对稳定性概念使用 Definition，功能不同。

**应用规则：**

- 记号缩写使用“记/令/denote/set”，不把普通组合单独命名为一种“性质”“机制”或“指标”。
- Definition 用于本文真正需要区分并据以推理的数学概念，准确给出条件和量词。已有标准定义只说明本文采用的含义或引用来源。
- 独立 Lemma 应有可单独调用的结论，或能隔离主证明中较长的技术部分。只用一次的较长关键技术引理仍可能有价值；三次规则不机械限制定理、引理数量。
- 能由现有公式和一句说明完成的计算留在正文中，不为形式感给每个步骤命名。

## 5. 按逻辑义务展开证明

**样本观察：** B pp.9–10 对引用的适定性定理逐项核验假设；B pp.12–15 用辅助能量、估计和积分推出稳定性；A pp.9–12 把构造、充分条件、可行性与最终估计分开。

**应用规则：** 先判断要证明什么，不预设套路。

**用户确认的详略标准：** 关键估计、条件使用和参数选择写清；直接代入和重复计算简写。短证明用连贯叙述，长证明有逻辑需要时才分 Step。这里控制新稿的证明表述；纯英文润色不据此补中间式或调整证明顺序。

| 证明义务 | 展开方式 |
| --- | --- |
| 调用已有定理 | 指明所用定理，核验当前对象满足其假设，然后写出所需结论 |
| 导出一个界 | 从被估计对象出发，给出关键等式/不等式，到达目标形式 |
| 存在性 | 给出合法构造或核验存在性定理的假设，不把形式表达式当作存在性证明 |
| 唯一性 | 建立两个候选解相等所需的估计，或调用已满足条件的定理 |
| 充要条件 | 两个方向分别成立，不把充分性当作必要性 |
| 反证法 | 写明否定的结论、由此得到的对象及其性质、最终与哪一条件矛盾 |
| 递推结论 | 初始情形、归纳假设和递推步完整，说明何以能够迭代 |

此表是通用的证明表述规则，不是声称每种方法都在样本中出现，也不保证它适合当前研究问题。推导有缺口时指出缺口，不用连接词补成“完整证明”。

## 6. 保留关键步骤，压缩机械计算

**应用规则：** 应展示决定结论的估计、耦合项的吸收、参数选择、边界项的处理、概率操作的合法性、无限和/极限交换的依据，以及从辅助量到目标范数的转换。

可以压缩已定义对象的直接代入、没有新困难的代数整理、真正相同的重复计算。按读者需要增减中间行，不以越长越严谨。

“类似可得”要使读者知道类比哪一步、替换什么、假设为何仍成立。不同边界条件、随机相关性或新的常数依赖不能简单略去。

使用 Young、Cauchy–Schwarz、Gronwall、Schur 补等工具时，说明它作用于哪一式或哪一项。随机积分取期望为零、极限交换等结论需要适当条件；不能从范文的行文简洁推断条件可省。

## 7. 常数依赖与参数选择次序

**样本观察：** A p.5 说明设计参数与截断阶数的关系，p.11 以量级估计讨论可行性；B pp.10–12 按参数与截断阶数展开可行性证明。

**用户偏好：** 不同估计尽量用不同下标常数，使它们能被逐一追踪。此偏好优先于一般论文中常见的可变常数 C 约定。

**应用规则：**

- 新稿中为不同来源或不同用途的估计优先使用 $C_1,C_2,\ldots$，说明必要依赖，在该论证内固定其含义。若仍使用同一个已确定的界，就沿用原常数，不为重复引用再命名。
- 不默认同一个 C 可以逐行改变，不把几个不同常数悄悄合并。确需统一上界时，明确建立其关系，再判断是否需要新符号。
- 常数需要可追踪不意味着一律展开成冗长显式表达式；数值形式只在参数选择或结果需要时给出。常数下标的区分可以构成三次使用原则的合理例外。
- 纯润色时保留原有常数记号；发现同名常数含义或依赖不清，只提出建议，不自行重新编号。
- 用于一致估计的常数，写清它独立于什么；普通固定参数不必每行重复说明。
- 先固定哪个参数、再选哪个小量、最后增大哪个阶数应当清楚且相容。常数若依赖这些量，保留依赖，避免循环选参。
- 声称充分大时可行，展示能支撑它的实际估计；已在前文证明则引用。不要只写一句“取足够大”。

## 8. 证明末尾回到原命题

**样本观察：** B p.12 联系能量与状态范数，p.15 从加权能量估计回到状态的均方指数估计。

**应用规则：** 写完中间量的界后，用已建立的比较关系得到定理要求的对象、范数和初值依赖，再结束证明。充分性、初值范围、概率意义和速率必须与原命题一致。

期望状态衰减不等于二阶矩衰减；有限样本路径衰减不构成几乎处处稳定证明；辅助误差衰减也未必意味着完整闭环稳定。

## 9. 措辞与阅读节奏

**样本观察：** A、B 用简短引导语连接具体构造和计算。借鉴其功能，不照搬冗句或语病。

**应用规则：**

- 英文直接说对象与动作，例如 “Substituting ... into ... gives ...”, “By ..., we obtain ...”, “Choose ... such that ...”。减少 “We now proceed to provide a detailed ...” 这类无信息铺垫。
- 表达精准优先于句式变化：区分 prove、derive、estimate、verify、suggest 所对应的实际工作。术语稳定，不为避免重复而给同一数学对象换同义词。
- 避免模板化过渡、空泛的 novel/significant/remarkable 评价、反复强调重要性和无依据的推广。不是机械禁词；有具体内容时保留必要表述。
- 连接词表达真实关系：combining 对应合并，by 对应工具或条件，therefore 对应推论，不随意互换。
- 一个核心估计配必要解释，不先预告一次、公式后翻译一次、段末再重复一次。
- 摘要和动机可以以文字为主；论文中的证明和技术论述要有适当公式。不设固定文字/公式比例，不将普通话语强行符号化；日常讲解不自动应用本技能。
- “最优”“任意”“首个”“充要”等措辞须有本文依据，不因范文语气强而扩大结论。

## 10. 篇章习惯只作辅助

A、B 常按具体问题、技术困难、构造、适定性/稳定性、证明和数值例子组织论文，Remark 用于解释设计或条件限制。此习惯仅在用户要求整篇组织时参考。本技能主要改善公式、证明和记号层面的表达，不强制复用章节数、控制方法或期刊格式。
